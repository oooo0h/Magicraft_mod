# 魔法工艺 mod · v1.8.0

适配游戏 1.2.43，需先安装 BepInEx 5。关闭游戏后，将 `InfiniteReroll.dll` 放入 `Magicraft/BepInEx/Plugins/` 下的 mod 文件夹，再启动游戏。更新时覆盖原 DLL，避免同时加载两份。

- **重铸炉**：免费、无限使用。选上方原法术，再点下方目标；候选保持相同星级和稀有度。
- **拖动**：在重铸面板按住法术 0.2 秒后，可调整背包和法杖槽位。
- **升星 / 拆分**：选中法术按 **G**，消耗三份同法术、同星级升一星；按 **H**，一份高星拆成三份低一星。也可开启面板内「自动升星」。
- **血色遗物**：在血色遗物房间按 **P**，从完整高级遗物目录自选购买，按原价消耗生命上限。可购买的排前面，各组价格从高到低；**P / Esc** 关闭。
- **召唤统计**：右下角药水栏上方自动显示召唤物头像和「场上数量 / 上限」，如啵啵 **3/5**、魔导书 **3/3**。只显示当前房间中玩家直属且存活的召唤物；魔导书、虫巢等召出的子代不计入。遗物和诅咒改变上限时同步更新。
- **统计面板**：左键按住标题、头像或空白处 **0.2 秒**后拖动，松开保存位置。未满为蓝灰背景，达到或超过上限为金褐背景；鼠标显示在面板上方。
- **自动补满**：默认开启，点击面板「自动补满：开 / 关」切换。当前手持法杖可直接施放、有明确数量上限的召唤物不足时自动施法，满了停止，退场后继续补；正常消耗魔力并遵守冷却。暂停、菜单、拖动或游戏失去焦点时停止，不自动切换法杖。

没有直属召唤物时，数量行隐藏；当前法杖仍可直接召唤时保留面板开关。退出游戏后移走 DLL 可停用 mod。
